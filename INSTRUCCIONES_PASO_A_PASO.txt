PROBLEMA 1: "dotnet: comando no encontrado" o no funciona
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Qué significa:
  → .NET SDK no está instalado en tu computadora

Solución:
  1. Ve a: https://dotnet.microsoft.com/download
  2. Descarga .NET 10.0
  3. Instala el ejecutable (.exe)
  4. REINICIA tu computadora
  5. Abre una terminal nueva
  6. Escribe: dotnet --version
  7. Si ves un número de versión, está instalado


PROBLEMA 2: "No se encuentra ServicioCierreCasos.csproj"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Qué significa:
  → Estás en la carpeta incorrecta

Solución:
  1. Abre Explorador de Archivos (WIN + E)
  2. Navega a: C:\ApostillaCcaycedo\ServicioCierreCasos
  3. Verifica que veas:
     - ServicioCierreCasos.csproj
     - Program.cs
     - ejecutar.bat
  4. Desde aquí ejecuta los scripts


PROBLEMA 3: "No se pudieron restaurar las dependencias"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Qué significa:
  → Problemas de internet o conexión a nuget.org

Solución:
  1. Verifica tu conexión a internet
  2. Si hay proxy/firewall, configúralo
  3. Intenta de nuevo
  4. Si sigue fallando:
     - Abre línea de comandos
     - Escribe: dotnet restore --no-cache


PROBLEMA 4: Errores de compilación (ej: "CS1234: ERROR")
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Qué significa:
  → Hay un error en el código fuente

Solución:
  1. Ejecuta: ejecutar-debug.bat (mostrará más detalles)
  2. Lee el error mostrado
  3. Busca el archivo y línea mencionada
  4. Verifica si hay errores de sintaxis
  5. Corrige el código


PROBLEMA 5: "No se puede conectar a la base de datos"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Qué significa:
  → La configuración de base de datos es incorrecta

Solución:
  1. Abre: appsettings.json
  2. Busca la sección "ConnectionStrings"
  3. Verifica que la ConnectionString sea correcta:
     - Server: Tu servidor SQL Server
     - Database: Tu nombre de base de datos
     - User Id: Tu usuario
     - Password: Tu contraseña
  4. Verifica que SQL Server esté ejecutándose
  5. Prueba la conexión desde SQL Server Management Studio
