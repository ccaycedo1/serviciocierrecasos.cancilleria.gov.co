# Diagrama de Flujo - Actualización de Estados de Pagos (v1.1)

## Flujo General del Job

```
┌─────────────────────────────────────────────────────────────────────┐
│                    INICIO DEL JOB                                   │
│            (Cada 5 minutos o bajo demanda)                          │
└──────────────────────────┬──────────────────────────────────────────┘
                           │
                           ▼
         ┌─────────────────────────────────────┐
         │  Obtener Pagos Pendientes           │
         │  (idEstado <> 4)                    │
         │  de AppPagosPagoNotificacion        │
         └──────────────┬──────────────────────┘
                        │
                        ▼
            ┌───────────────────────┐
            │ ¿Hay registros?       │
            └────┬──────────────┬───┘
            NO   │              │  SÍ
                 │              │
            ┌────▼──────┐       │

            │  LOG       │       │
            └────────────┘       │

              ┌──────────────────────────────────┐
              │  Para cada Pago:                 │
              │  1. Extraer ID Recaudo           │
              │  2. Buscar en tbRecaudo          │
              │  3. Evaluar codEstadoRecaudo    │
              └───────────┬──────────────────────┘
                          │
            ┌─────────────┴─────────────┐
            │                           │
        FLUJO A              FLUJO B (NUEVO)
     codEstadoRecaudo     codEstadoRecaudo
          = 2                   <> 2
            │                   │

    │ estado pago  │    │ PagosRetransmitidos  │
    │ a estado 4   │    │                      │
    └──────┬───────┘    └────────┬─────────────┘
           │                     │
           ▼                     ▼
    Contador:         ┌──────────────────┐
    Registros         │¿Existe Registro? │
    Actualizados      └────┬──────────┬──┘
                        NO │          │ SÍ
                           │          │
                      ┌────▼──┐       ▼
                      │Skip   │   Actualizar
                      │       │   fechaRetransmision
                      └───────┘   = NULL
                           │       │
                           │       ▼
                           │  Contador:
                           │  Registros
                           │  Actualizados
                           │       │

                               │
                               ▼
           ┌───────────────────────────────┐
           │ ¿Más Pagos?                   │
           └────┬──────────────────────┬───┘
            SÍ  │                      │  NO
                │                      │
            ┌───▼──┐                   │
            │Loop  │                   │
            └───┬──┘                   │
                │                      │
                └──────────┬───────────┘
                           │
                           ▼
           ┌───────────────────────────────┐
           │ Finalizar Log de Ejecución    │
           │ - Registros Consultados       │
           │ - Registros Actualizados      │
           │ - Registros Sin Coincidencia  │
           │ - Errores                     │
           │ - Duración Total              │
           └───────────┬───────────────────┘
                       │

              ┌────────────────────┐
```

## Estados y Decisiones

### Variable: `codEstadoRecaudo`

| Estado | Acción                           | Destino              |
|--------|----------------------------------|----------------------|
| **2**  | Cierre de Registro (FLUJO A)     | Actualizar pago      |
| **1**  | Búsqueda Retransmisión (FLUJO B) | Buscar PagosRetrans  |
| **3**  | Búsqueda Retransmisión (FLUJO B) | Buscar PagosRetrans  |
| **4+** | Búsqueda Retransmisión (FLUJO B) | Buscar PagosRetrans  |

## Tablas Involucradas

```
┌─────────────────────────────────┐
│   Apostilla.dbo.tbRecaudo       │
├─────────────────────────────────┤
│ ✓ idRecaudo (PK)                │
│ • codEstadoRecaudo ◄─── Decisor │
└─────────────────────────────────┘
            │
            └─► Decide Flujo
                │
                ├─► FLUJO A: codEstadoRecaudo = 2
                │            └─► Update AppPagosPagoNotif
                │
                └─► FLUJO B: codEstadoRecaudo ≠ 2
                             └─► Query referencia completa
                                 └─► Update PagosRetransmitidos

┌─────────────────────────────────────────┐
│ Pagos.pse.AppPagosPagoNotificacion      │
├─────────────────────────────────────────┤
│ ✓ id (PK)                               │
│ • referenciaPago ◄─── FLUJO B consulta  │
│ • idEstado ◄─── FLUJO A actualiza       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ Pagos.tarjetaCredito.PagosRetransmitidos│
├─────────────────────────────────────────┤
│ ✓ id (PK)                               │
│ • referencia ◄─── FLUJO B busca         │
│ • fechaRetransmision ◄─── FLUJO B =NULL │
└─────────────────────────────────────────┘
```

## Gestión de Errores

```
Durante cualquier paso:

┌─────────────────────────────────┐
│ ¿Excepción?                     │
└────┬──────────────────┬─────────┘
   NO│                  │SÍ
     │                  │
     ▼                  ▼
  Continuar      ┌──────────────┐
  proceso        │ Registrar    │
     │           │ Error en Log │
     │           │ Contador++   │
     │           │ No interrup. │
     │           └──────┬───────┘
     │                  │
     └──────────┬───────┘
                │
                ▼
         Continuar Loop
         siguiente pago
```
