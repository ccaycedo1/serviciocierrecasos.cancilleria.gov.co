┌────────────────────────────────────────────────────────────────────────────┐
│ OPCIÓN 2: COMPILAR Y EJECUTAR (Alternativa manual)                        │
└────────────────────────────────────────────────────────────────────────────┘

Paso 1 - Ir a la carpeta del proyecto:
    cd C:\ApostillaCcaycedo\ServicioCierreCasos

Paso 2 - Compilar:
    dotnet build ServicioCierreCasos.csproj --configuration Debug

Paso 3 - Ejecutar:
    dotnet bin\Debug\net10.0\ServicioCierreCasos.dll


┌────────────────────────────────────────────────────────────────────────────┐

EXPLICACIÓN DE LOS COMANDOS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

cd C:\ApostillaCcaycedo\ServicioCierreCasos
  → Cambia al directorio del proyecto

ejecutar.bat
  → Ejecuta el script de depuración completo

dotnet build
  → Compila el proyecto

dotnet restore
  → Restaura las dependencias NuGet

dotnet clean
  → Limpia artefactos compilados anteriormente

--configuration Debug
  → Compilación en modo depuración (con símbolos de debug)

--configuration Release
  → Compilación en modo producción (optimizada)

-v diagnostic
  → Verbosidad máxima para diagnósticos

--no-restore
  → Compila sin restaurar dependencias

dotnet bin\Debug\net10.0\ServicioCierreCasos.dll
  → Ejecuta el programa compilado

&&
  → Ejecuta el siguiente comando si el anterior fue exitoso
